# UI/UX Pro Max

Comprehensive design system patterns and visual engineering standards for mobile and desktop applications.

## Design Systems & Tokens
- **Theme Palette**:
  - Dark mode and light mode semantic color tokens with high dynamic contrast.
  - Consistent surface tiers (Surface Level 0, Surface Level 1, Floating/Overlays).
- **Glassmorphism & Depth**:
  - Subtle blur effects (`backdrop-filter: blur(16px)` to `blur(24px)`).
  - 1px hairline border highlights (`rgba(255, 255, 255, 0.08)`) with soft multi-layered drop shadows.
- **Empty, Loading & Error States**:
  - Empty states must provide immediate guidance and direct primary call-to-actions.
  - Loading states use polished skeletons or non-jarring indicators matching page layout.
  - Errors must be non-intrusive, descriptive, and recoverable.
- **Data Visualizations**:
  - Financial charts (bars, breakdown rings, timelines) must render accurately with legible labels and high contrast data indicators.
